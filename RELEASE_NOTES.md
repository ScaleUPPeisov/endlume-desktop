# ENDLUME Studio 1.0.0-alpha.8.6 — 14.08.2026 · macOS Apple Silicon

- Новая чистая macOS-иконка ENDLUME: цветной interlocking-loop без старой двойной рамки.
- Effects, Subscribe и ambient получили отдельные ВКЛ/ВЫКЛ без удаления сохранённых настроек.
- Subscribe теперь можно удалить прямо из редактора; для Effects и Subscribe добавлено явное включение/выключение пресета.
- Live Preview исправлен: перемещение и изменение размера идут сразу через requestAnimationFrame, без FFmpeg и записи библиотеки на каждый пиксель движения; обработчики совместимы с React 19.
- Быстрый встроенный preview на Mac: Apple VideoToolbox, 60 FPS proxy 960×540, короткий preview-клип и ограниченный preview-cache.
- Ускорен рендер overlay-эффектов: chromakey/luma кэш теперь заранее масштабирует небольшие overlay-видео в lossless qtrle, вместо декодирования полноразмерного 4K overlay при каждом появлении.
- Финальное разрешение, выбранный битрейт и существующий качественный аудиопайплайн сохранены; финальный mux по-прежнему выполняется без лишнего повторного кодирования.
- В Render Center показывается реальное состояние SSD для папки вывода: использовано / свободно / всего, обновление раз в секунду во время рендера.
- Кнопка «Проверить и обновить» теперь сама проверяет, скачивает, устанавливает подписанное обновление и перезапускает ENDLUME.
