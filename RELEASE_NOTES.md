# ENDLUME Studio 1.0.0-alpha.8.9 — 15.08.2026 · macOS Apple Silicon

- Исправлена причина появления клонов после обновления: на macOS ENDLUME теперь использует один жёсткий канонический путь `/Applications/ENDLUME Studio.app`.
- Перед установкой обновления Single App Guard проверяет bundle ID `studio.endlume.desktop`, удаляет старые дубликаты и не запускает updater из случайной копии на Рабочем столе, в Downloads или под старым именем.
- Если приложение запущено не из `/Applications/ENDLUME Studio.app`, оно сначала переносит актуальную копию в каноническое место и автоматически перезапускается. Только после этого разрешается обновление.
- После установки выполняется повторная очистка дубликатов; при каждом следующем запуске ENDLUME снова проверяет, что осталась одна установка.
- Автопроверка обновлений теперь постоянная: при запуске, при возврате в окно и каждые 5 минут, пока ENDLUME открыта.
- При появлении новой версии карточка обновления показывается сама. Кнопка «Напомнить через час» ставит уведомление на паузу на 60 минут, после чего оно снова появится автоматически.
- История обновлений дополнена alpha.8.9; все предыдущие релизы остаются доступными в Настройки → Обновления.
