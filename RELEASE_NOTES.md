# ENDLUME Studio 1.0.0-alpha.8.8 — 15.08.2026 · Windows x64

- Новый Ultra Static Engine для типового проекта «1 изображение + 15 песен».
- Для неподвижного изображения используется короткий 2 FPS master: визуальная картинка остаётся той же, но повторяющихся видеопакетов примерно в 30 раз меньше, чем при 60 FPS.
- Длинный ролик собирается без повторного видеокодирования: video stream-copy + audio stream-copy.
- Совместимые AAC/MP3/ALAC/AC3/EAC3 треки копируются byte-for-byte, без повторного AAC-кодирования и дополнительной потери звука.
- FFprobe объединён в один проход на трек: длительность, codec, sample rate, channels и bitrate больше не требуют двух отдельных запусков.
- Битрейт статичного master автоматически учитывает реальный bitrate исходной музыки и ориентируется примерно на 1 ГБ на 2 часа.
- Первый I-frame статичного master принудительно кодируется с высоким качеством; масштабирование выполняется Lanczos.
- Убраны лишние многочасовые промежуточные аудиофайлы, повторные проходы и перемещение большого финального файла.
- Если original stream-copy небезопасен или включены Effects / Subscribe / ambient / LUFS, ENDLUME автоматически использует обычный качественный движок.
- Подписанный updater остаётся встроенным: Windows обновляется из «Настройки → Обновления» без ручной переустановки.
