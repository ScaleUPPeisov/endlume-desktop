# ENDLUME Studio 1.0.0-alpha.8.10 — 15.08.2026 · macOS Apple Silicon

- Исправлен Fast Engine Benchmark: ENDLUME больше не может показывать кодировщик «выбранным», если тот же тест отметил его как недоступный.
- Benchmark сначала читает реальный список кодировщиков комплектного FFmpeg, затем каждым найденным движком создаёт короткий тестовый MP4. Победителем становится только успешно отработавший кодировщик.
- На macOS проверяются `h264_videotoolbox`, `hevc_videotoolbox` и `libx264`; для VideoToolbox используется реальный MP4-контейнер, `yuv420p` и разрешён software fallback для корректной диагностики.
- Вместо общей надписи «недоступен» интерфейс показывает, где именно проблема: кодировщика нет в FFmpeg либо он есть, но реальный encode-test завершился ошибкой. Последняя диагностическая ошибка FFmpeg показывается прямо в Fast Engine.
- Release CI дополнительно проверяет, что комплектный macOS FFmpeg действительно содержит `h264_videotoolbox`, `hevc_videotoolbox` и `libx264`, а `libx264` реально создаёт тестовый MP4 ещё до сборки приложения.
- В интерфейсе пояснено, что `Кэш Effects: 0 файлов` — нормальное состояние до первой подготовки эффекта и само по себе не означает ошибку.
- Сохранены все изменения alpha.8.9: одна установка `/Applications/ENDLUME Studio.app`, очистка клонов, постоянная проверка обновлений и полная история предыдущих версий.
