# ENDLUME Studio 1.0.0-alpha.8.13 — 23.08.2026 · macOS Apple Silicon

- Effects и Subscribe переведены на новый GPU Live Preview: базовое изображение/видео остаётся на экране, а chromakey/luma/screen композятся через WebGL прямо в интерфейсе.
- Положение и размер эффекта меняются вместе с реальным содержимым на частоте дисплея. Во время drag/resize FFmpeg и React-state не запускаются; состояние сохраняется после отпускания мыши.
- Убрана схема, при которой после каждого перемещения приходилось ждать новый MP4 preview. Для первого открытия создаётся короткий proxy, дальше используется кэш; предыдущий кадр не очищается во время обновления proxy.
- Proxy на Mac сначала использует Apple VideoToolbox, а при его недоступности автоматически откатывается на libx264 ultrafast, чтобы Live Preview не превращался в чёрный экран.
- Карточки «Режим зацикливания», числовые значения, пресеты, ползунки и кнопки дополнительно приведены к более компактному dark-glass / cyan-violet-pink стилю LoopForge.
- Для Image, Crossfade, Ping-pong и «Без обработки» добавлен отдельный release smoke-suite: 25 реальных FFmpeg-прогонов на каждый режим, всего 100 проверок на релиз.
- Цель 400–500 МБ для двухчасового ролика специально НЕ включена. При фиксированном размере 400–500 МБ нельзя одновременно гарантировать строгую сохранность исходного качества изображения и музыки; ENDLUME не будет ухудшать качество ради этой цифры.
- Существующая логика Smart Size, финального stream-copy mux, Fast Engine, очереди и подписанного in-place updater сохранена.
