# ENDLUME 1.0 — DESIGN LOCK

## Неприкосновенное правило
ENDLUME визуально и по последовательности работы максимально близок к LoopForge, который пользователь предоставил на скриншотах.
Переход на Tauri 2 + Rust НЕ является поводом менять дизайн продукта.

## Основной экран
- DARK only.
- Центрированный бренд ENDLUME сверху.
- Один чистый вертикальный рабочий экран.
- Большая dashed-зона исходных файлов.
- 2x2 карточки Image / Crossfade / Ping-pong / Без обработки.
- Параметры рендера ниже: resolution / FPS / codec / preset / duration / bitrate.
- Тонкие аккуратные sliders, крупное текущее значение справа.
- Toggle-переключатели.
- Отдельные компактные строки Subscribe / Effects / Ambient.
- Выбранные папки и output внизу.
- Кнопка «Добавить в очередь» внизу.

## Верхняя навигация
Компактно: Проект / Рендер / Библиотека / Настройки.
Не делать тяжёлый sidebar/dashboard.

## Render Center
- LoopForge-like layout.
- Слева вертикальные карточки очереди.
- Справа текущий/выбранный проект.
- Время рендера / длительность / размер / аудиотреки / encoder / CPU / RAM.
- Плавный % и стадии.
- Общий прогресс очереди снизу.
- После завершения: Открыть видео / Открыть папку / Повторить / Удалить.

## Editors
Effects и Subscribe остаются внутри одного окна ENDLUME.
Большой Preview + timeline + direct drag/resize мышью.
Controls минимальны и визуально соответствуют LoopForge.

## Запрещено без отдельного согласования пользователя
- cyberpunk dashboard;
- огромные панели статистики на главном экране;
- отдельные OS-окна для Render/Effects/Subscribe/Settings;
- новый визуальный язык, не похожий на LoopForge;
- «профили каналов».
