# ENDLUME Studio 1.0.0-alpha.8.11 — 15.08.2026 · macOS Apple Silicon

- В Настройки → Обновления теперь доступна полная сохранённая история alpha-релизов от 1.0.0-alpha.8.1 до текущей версии. Каждую версию можно раскрыть отдельно и посмотреть список изменений.
- Возвращены ранее не показанные пункты alpha.8.1 и alpha.8.2; история больше не начинается с alpha.8.3.
- Каноническое имя приложения закреплено как `ENDLUME Studio.app`. Старые установки с именами вроде `ENDLUME Studio alpha8.3 backup.app` автоматически переносятся в `/Applications/ENDLUME Studio.app` и перезапускаются уже с нормальным именем.
- Single App Guard продолжает гарантировать одну установку с bundle ID `studio.endlume.desktop` и удаляет старые дубликаты.
- Сохранено исправление Fast Engine из alpha.8.10: Benchmark не может показывать кодировщик выбранным, если его тест не прошёл; для каждого движка отображается реальная причина ошибки FFmpeg.
- На macOS Benchmark проверяет `h264_videotoolbox`, `hevc_videotoolbox` и `libx264` реальным коротким MP4 encode-test.
- Нулевой Effects cache остаётся нормальным до первого фактического использования эффекта.
