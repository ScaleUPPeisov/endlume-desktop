# ENDLUME Studio 1.0.0-alpha.8.7 — 15.08.2026 · macOS Apple Silicon

- Single App Guard: ENDLUME определяет текущий `.app` по стабильному bundle ID `studio.endlume.desktop`, ищет старые копии через Spotlight и стандартные папки macOS и удаляет старые/дублирующиеся экземпляры, не трогая смонтированные DMG.
- Подписанный Tauri Updater продолжает обновлять текущий запущенный `ENDLUME Studio.app` in-place; перед и после установки выполняется проверка старых копий, затем автоматический перезапуск.
- В Настройки → Обновления добавлен статус Single App Guard и ручная кнопка удаления защищённых старых копий с системным запросом прав только при необходимости.
- Перетаскивание и изменение размера Effects/Subscribe теперь выполняется напрямую через DOM + `requestAnimationFrame`, без обновления React/Zustand на каждый пиксель. Состояние записывается один раз после отпускания мыши.
- Live Preview остаётся встроенным: короткий 960×540 proxy, 60 FPS, аппаратный Apple VideoToolbox; тяжёлый FFmpeg-preview не пересобирается во время самого drag.
- Сохранены отдельные ВКЛ/ВЫКЛ и УДАЛИТЬ для Effects/Subscribe, глобальные ВКЛ/ВЫКЛ для Effects/Subscribe/Ambient и удаление ambient-файла.
- Сохранён быстрый overlay pipeline alpha.8.6: chromakey/luma предварительно кэшируются и масштабируются один раз в lossless qtrle; финальный длинный mux использует `-c:v copy -c:a copy` вместо повторного кодирования всего ролика.
- Финальное разрешение и выбранный видеобитрейт сохраняются. Музыкальная дорожка не перекодируется повторно на финальном mux; если включены crossfade/normalization/ambient, аудио обрабатывается один раз в 320 кбит/с, 48 kHz stereo.
- Render Center показывает реальное состояние диска папки вывода — использовано / свободно / всего — с обновлением каждую секунду, одновременно с живым временем и прогрессом.
- Новая чистая macOS-иконка ENDLUME из `app-icon-v2.svg` продолжает пересобираться в `.icns` для каждого релиза.
- Release CI дополнительно распаковывает updater и проверяет: внутри ровно один `ENDLUME Studio.app`, bundle ID неизменен, версия совпадает во frontend/Rust/Tauri и новая иконка присутствует.
