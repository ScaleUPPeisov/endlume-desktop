# ENDLUME Studio 1.0.0-alpha.8.12 — 15.08.2026 · macOS Apple Silicon

- Обновлена только верхняя навигация ENDLUME Studio: кнопки `Проект`, `Рендер`, `Библиотека`, `Настройки` стали компактнее и визуально легче.
- Активная вкладка получила премиальную cyan/violet/pink подсветку, тонкий градиентный контур, мягкое свечение и деликатный движущийся световой блик.
- Неактивные вкладки получили более спокойный dark-glass фон и лёгкий glow при наведении, без лишней яркости.
- Уменьшены высота кнопок, внутренние отступы, иконки и бейдж активных рендеров — навигация больше не выглядит громоздкой.
- Добавлена поддержка `prefers-reduced-motion`: если в macOS отключены анимации, движущийся блик автоматически становится статичным.
- Логика переходов, рендер, Fast Engine, библиотека, настройки и все остальные функции приложения не изменялись.
