# ENDLUME Studio 1.0.0-alpha.8.8 — 15.08.2026 · macOS Apple Silicon

- В Настройки → Обновления добавлена полноценная история релизов: alpha.8.3, alpha.8.4, alpha.8.5, alpha.8.6, alpha.8.7 и текущая alpha.8.8. Каждую версию можно раскрыть и посмотреть полный список изменений.
- Исправлено имя приложения в Finder/Dock: если старая установка физически называется `ENDLUME Studio alpha8.3 backup.app` или иначе, ENDLUME автоматически переименовывает текущий bundle в канонический `ENDLUME Studio.app`.
- После переименования приложение автоматически запускается заново уже из нового канонического пути. Следующие подписанные обновления продолжают обновлять это же одно приложение.
- Single App Guard теперь проверяет одновременно стабильный bundle ID `studio.endlume.desktop`, число копий и фактическое имя текущего `.app`.
- В Настройки → Обновления показывается фактический путь текущей установки и отдельная ручная кнопка «Исправить имя → ENDLUME Studio», если автоматическая нормализация не была выполнена.
- Сохраняются все исправления alpha.8.7: один app, быстрый display-synced drag Effects/Subscribe, VideoToolbox Live Preview, pre-scaled lossless overlay-cache, ВКЛ/ВЫКЛ/удаление Effects/Subscribe/Ambient, живая SSD-телеметрия и подписанный in-place updater.
