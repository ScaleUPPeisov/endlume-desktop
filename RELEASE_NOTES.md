# ENDLUME Studio 1.0.0-alpha.8.18 — 24.08.2026 · macOS Apple Silicon

- Исправлен критический сбой обычного проекта «1 изображение + MP3». Локальный release-gate реально собирает end-to-end тестовый MP4 с одним PNG и музыкальным циклом; установка блокируется, если в результате нет видео или аудио.
- Исправлена совместимость музыкальных папок с разными MP3: каждый трек перед acrossfade приводится к 48 kHz, stereo и sample format fltp. Проверяются mono/stereo и 32/44.1/48 kHz.
- В regression-test используются Unicode, кириллица, французские символы, типографские кавычки и пробелы в именах файлов, включая сценарий, похожий на обычную пользовательскую папку.
- Добавлено самовосстановление путей проекта. Если после обновления или перемещения папки старые пути к PNG/MP3 стали невалидны, ENDLUME перед рендером повторно читает выбранную папку проекта и подхватывает актуальные файлы.
- Выключенные Effects и Subscribe полностью исключаются из подготовки кэша и не обращаются к source-файлам. Старый удалённый файл выключенного пресета больше не может уронить обычный рендер.
- Если включённый старый Effects/Subscribe ссылается на потерянный файл или не может подготовиться, ENDLUME пропускает только этот overlay с предупреждением и продолжает основной рендер.
- Новые Effects, Subscribe и ambient после выбора копируются во внутреннюю managed-библиотеку ENDLUME в Application Data. После импорта пресет не зависит от исходного файла в Downloads, Desktop или другой внешней папке.
- При первом запуске alpha.8.18 библиотека автоматически мигрирует старые доступные Effects/Subscribe/Ambient во внутреннее хранилище. Потерянные legacy-файлы автоматически выключаются и очищаются из source, поэтому больше не вызывают «файл не найден» в Live Preview или рендере.
- Импорт Effects и Subscribe теперь показывает реальную ошибку пользователю, если копирование не удалось, вместо молчаливого сбоя кнопки.
- GPU Live Preview не запускается для пустого/потерянного source. Для валидных overlays сохраняется VideoToolbox → libx264 fallback и live drag/resize без повторного FFmpeg во время движения.
- Исправлено зависание «ПРОВЕРЯЮ…» в Настройки → Обновления. Проверка updater имеет жёсткий таймаут 12 секунд и всегда возвращает интерфейс из busy-state.
- Все автоматические macOS GitHub Actions для ENDLUME отключены. Они больше не запускаются на push и не расходуют GitHub-hosted macOS minutes; оба workflow оставлены только как ручной fallback.
- Добавлен `BUILD_ENDLUME_LOCAL.command`: он на Mac Apple Silicon сам получает release-исходники, применяет render/editor hotfix, прогоняет 100 Loop Mode тестов и normal-folder regression, проверяет React + Rust, локально собирает `ENDLUME Studio.app` и заменяет текущую программу в `/Applications` без создания второй копии.
- Локальная сборка не создаёт и не публикует online updater artifact. GitHub используется только как приватное хранилище исходников; GitHub Actions при локальной установке не запускаются.
- Сохранены предыдущие исправления интерфейса: нативная плавная прокрутка macOS, безопасные route-переходы без поломки fixed footer, GPU Live Preview Effects/Subscribe, Live drag/resize и Single App Guard.
